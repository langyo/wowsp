# 使用量遙測告知

**自 WoWSP 0.4 起生效。**

WoWSP 會收集極少量使用量遙測資料，用於了解哪些功能被實際使用，並指導後續開發。本告知說明收集的確切內容、絕不收集的內容，以及資料的處理方式。

## 我們收集什麼

- **介面語言**。即作業系統所回報的語言，用於了解應用各語言介面在實際使用中的佔比；不會據此推斷任何其他輸入或偏好。
- **應用內開啟了哪些頁面**（路由層級的頁面瀏覽，例如主面板或回放頁）。
- **大致地區**（由 IP 位址按國家層級推斷）以及每日活躍安裝量的粗略統計。完整 IP 位址本身不會被儲存。

## 我們絕不收集什麼

- 可識別個人身分的資訊：沒有姓名、沒有電子郵件、沒有遊戲帳號識別碼。
- 你的回放內容、玩家暱稱，或任何與帳號綁定的遊戲內資料。
- 檔案系統內容、設定值，或你在應用中輸入的任何內容。

## 資料如何處理

遙測資料由 Google Analytics 接收，並按 Google 的標準資料處理條款保留。資料僅用於功能使用情況的統計彙總；絕不出售、不用於行銷目的與第三方共享，也不用於建立個人畫像。

## 關閉遙測

桌面版的遙測僅限於上述功能使用訊號，且在你完成首次啟動精靈之前不會進行任何收集。應用完全開放原始碼，遙測相關程式碼路徑可隨時在儲存庫中查閱。
