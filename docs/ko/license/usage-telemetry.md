# 사용량 원격 측정(텔레메트리) 안내

**WoWSP 0.4 이상에 적용됩니다.**

WoWSP는 어떤 기능이 실제로 사용되는지 파악하고 향후 개발 방향을 정하기 위해 아주 적은 양의 사용량 텔레메트리를 수집합니다. 이 안내문은 수집하는 항목, 절대 수집하지 않는 항목, 그리고 데이터 처리 방식을 설명합니다.

## 수집하는 항목

- **인터페이스 언어.** 운영체제가 보고하는 언어로, 앱의 각 UI 언어가 실제로 얼마나 사용되는지 파악하는 용도로만 사용됩니다. 이를 통해 다른 입력이나 설정을 추론하지 않습니다.
- **앱에서 어떤 페이지가 열렸는지**(대시보드, 리플레이 화면 등 라우트 단위 페이지뷰).
- **대략적인 지역**(IP 주소에서 국가 수준으로 추정)과 일일 활성 설치 수의 대략적인 집계. 전체 IP 주소 자체는 저장되지 않습니다.

## 절대 수집하지 않는 항목

- 개인 식별 정보: 이름, 이메일 주소, 게임 계정 식별자 등.
- 리플레이 내용, 플레이어 닉네임, 계정과 연결된 게임 내 데이터.
- 파일 시스템 내용, 설정값, 앱에 입력한 내용.

## 데이터 처리 방식

텔레메트리는 Google Analytics로 전송되며 Google의 표준 데이터 처리 약관에 따라 보관됩니다. 데이터는 기능 사용 통계 집합에만 사용되며, 판매되거나 마케팅 목적으로 제3자와 공유되거나 개인 프로필을 만드는 데 사용되지 않습니다.

## 텔레메트리 비활성화

데스크톱 버전의 텔레메트리는 위의 기능 사용 신호로 제한되며, 첫 실행 마법사를 완료하기 전에는 어떤 수집도 이루어지지 않습니다. 앱은 완전히 오픈 소스이므로 텔레메트리 관련 코드는 언제든지 저장소에서 확인할 수 있습니다.
