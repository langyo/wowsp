# 使用量遥测告知

**自 WoWSP 0.4 起生效。**

WoWSP 会收集极少量使用量遥测数据，用于了解哪些功能被实际使用，并指导后续开发。本告知说明收集的确切内容、绝不收集的内容，以及数据的处理方式。

## 我们收集什么

- **界面语言**。即操作系统所报告的语言，用于了解应用各语言界面在实际使用中的占比；不会据此推断任何其他输入或偏好。
- **应用内打开了哪些页面**（路由级别的页面浏览，例如主面板或回放页）。
- **大致地区**（由 IP 地址按国家级别推断）以及每日活跃安装量的粗略统计。完整 IP 地址本身不会被存储。

## 我们绝不收集什么

- 可识别个人身份的信息：没有姓名、没有电子邮箱、没有游戏账号标识。
- 你的回放内容、玩家昵称，或任何与账号绑定的游戏内数据。
- 文件系统内容、配置值，或你在应用中输入的任何内容。

## 数据如何处理

遥测数据由 Google Analytics 接收，并按 Google 的标准数据处理条款保留。数据仅用于功能使用情况的统计汇总；绝不出售、不用于营销目的与第三方共享，也不用于构建个人画像。

## 关闭遥测

桌面版的遥测仅限于上述功能使用信号，且在你完成首次启动向导之前不会进行任何收集。应用完全开源，遥测相关代码路径可随时在仓库中查阅。
