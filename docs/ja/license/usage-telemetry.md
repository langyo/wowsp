# 利用統計（テレメトリー）に関する通知

**WoWSP 0.4 以降に適用。**

WoWSP は、どの機能が実際に使われているかを把握し、今後の開発に役立てるため、ごく少量の利用統計（テレメトリー）を収集します。この通知では、収集する内容、決して収集しない内容、データの取り扱いについて説明します。

## 収集するもの

- **インターフェースの言語。** オペレーティングシステムが報告する言語で、アプリの各 UI 言語の実際の使用状況を把握するためだけに使われます。これから他の入力や設定を推測することはありません。
- **アプリ内でどのページが開かれたか**（ルート単位のページビュー。ダッシュボードやリプレイ画面など）。
- **おおよその地域**（IP アドレスから国レベルで推定）と、1 日あたりのアクティブなインストール数の概数。完全な IP アドレスそのものは保存されません。

## 決して収集しないもの

- 個人を特定できる情報：氏名、メールアドレス、ゲームアカウントの識別子など。
- リプレイの内容、プレイヤーのニックネーム、アカウントに紐づくゲーム内データ。
- ファイルシステムの内容、設定値、アプリに入力された内容。

## データの処理方法

テレメトリーは Google Analytics に送信され、Google の標準的なデータ処理規約に従って保持されます。データは機能利用統計の集計のみに使用され、販売、マーケティング目的での第三者への共有、個人のプロファイル作成に使用されることは一切ありません。

## テレメトリーの無効化

デスクトップ版のテレメトリーは上記の機能利用シグナルに限定され、初回起動ウィザードを完了するまで一切の収集は行われません。アプリは完全にオープンソースであり、テレメトリー関連のコードはいつでもリポジトリで確認できます。
