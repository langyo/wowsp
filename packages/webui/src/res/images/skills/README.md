# Skill icons

Real in-game commander-skill icons, one per skill code (snake_case of the
GameParams Crew skill code). Sourced from the WoWs-ShipBuilder asset pack
(square 60x60 art — the live client stores unusable 122x22 silhouette strips
at gui/crew_commander/skills) and converted to webp by
`scripts/extract/build_planner_data.py`. Regenerate via
`python scripts/extract/build_planner_data.py` (needs the `just extract`
GameParams cache for the code list).
